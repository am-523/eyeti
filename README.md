# EYETI — 75% Mechanical Keyboard

An interactive sound-therapy mechanical keyboard showcase featuring high-performance canvas scroll-driven animations, Lenis smooth scrolling, and responsive acoustic telemetry.

## ✨ Features

- **240-Frame Scroll Sequence**: Smooth frame-by-frame canvas scrubbing linked with scroll position.
- **Lenis Smooth Scroll**: Inertial, fluid page scrolling experience.
- **Sound Therapy Telemetry**: Acoustic lab aesthetic, real-time switch and sound frequency analytics.
- **Interactive Preloader**: Telemetry status and progress bar during asset calibration.
- **Responsive & Modern Design**: Dark aesthetic inspired by acoustic labs and precision engineering.

## 🛠️ Tech Stack

- **Vite** — Next generation frontend tooling
- **HTML5 & Vanilla CSS** — Custom typography and dark technical aesthetic
- **JavaScript (ES Modules)** — Canvas frame rendering engine
- **Lenis** — Modern smooth scroll library

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/am-523/eyeti.git
cd eyeti
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```

### 4. Build for production
```bash
npm run build
```
